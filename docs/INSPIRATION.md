# Inspiration and scope

Research date: 2026-11-10. Primary SideFX product sources were retrieved through web search.

## Primary sources

- [Houdini procedural modeling, retopology and point clouds](https://www.sidefx.com/products/houdini/modeling/): describes editable, repeatable modeling stages and a node-based, non-destructive approach.
- [Houdini FX features](https://www.sidefx.com/products/houdini/fx-features/): describes particle tools as rules composed from sources, forces, attractors, and collisions, alongside advanced physical simulation systems.
- [Houdini Core features](https://www.sidefx.com/products/houdini/core-features/): describes procedural workflows and packaging editable operations into reusable assets.
- [Houdini node documentation](https://www.sidefx.com/docs/houdini/nodes): documents distinct operator systems and how networks compose operations.

## Distilled interaction

The kata captures the approachable idea of **a source, followed by editable operations, followed by an output**. A seeded source plus a few visible parameters makes cause and effect understandable. Operator order, bypass, and reordering are functional rather than decorative.

The scope intentionally excludes the major technical machinery of Houdini. Fluxgrove is a small Canvas 2D renderer of procedurally transformed 3D points. Its turbulence and waves are analytic, time-varying fields, not physical simulation. There is no claim of Houdini parity, compatibility, or equivalent node architecture.

## Original work

The Fluxgrove name, earthy color system, botanical copy, eight-spoke logo, CSS thumbnail motifs, UI arrangement, code, and generated point studies were made for this kata. No SideFX logo, screenshot, interface artwork, scene, documentation text, or proprietary asset was imported.
